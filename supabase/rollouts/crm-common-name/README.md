# 共通顧客の名前

名前（普段の呼び名）は既存の `nickname`、フルネームは `name`、ふりがなは `name_yomi` に保存する。既存値の移行は行わない。旧顧客はフルネームがある限り名前未登録のまま編集できる。名前を登録した後は、名前を空欄に戻せない。フルネームを空欄にするには名前が必要になる。

DBの変更とアプリ公開には別途承認が必要。既存値と権限を適用前後に照合する。SQLを先に適用し、新画面を公開するまで旧画面からのCRM新規登録とLillyでの呼び名編集を停止する。旧画面は共通の名前必須条件と、Lillyの専用編集から共通編集へ移した呼び名入力を案内できない。

不具合時は入力済みデータを保持して旧画面へ戻す。切り戻し中は新規登録、氏名なし顧客の旧画面での編集、Lilly専用欄での呼び名編集を停止する。RLS・RPCの権限と旧サービス行の保持を確認してから再開する。
